# Glitch asset list

Convention: `parts/<part>[_l|_r][_open|_fist].png`. `l`/`r` are anatomical sides; for the default right-facing view, `l` is near/front and `r` is far/back. Variant suffixes share one attachment slot. Exact bone, parent, draw order, visibility, and normalized pivot for every file are stored in `manifest.json`.
